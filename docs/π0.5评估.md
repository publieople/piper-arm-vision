# π0.5 评估结论（2026-11-10 实测）

## 硬数据
- openpi 仓库 `Physical-Intelligence/openpi`，pi05_droid / pi05_libero 均为 **3,353,433,872 参数**，参数树 **12.49 GB**（与 checkpoint 12.4GB 一致，按 bf16 存）。
- 4070 Laptop 8GB（实际可用约 5.7GB）：模型 `create()` 阶段就 RESOURCE_EXHAUSTED，单块申请 4.83GB 失败。
- 结论：**本地 8GB 跑不了 π0.5**，参数比显存还大。推理至少 16GB（实际建议 24GB），LoRA 微调需 >22.5GB，全量 >70GB。
- 下载：GCS 直连本机 0.6MB/s（12.4GB 要 4~6 小时）；itbk 上 13.9MB/s（约 15 分钟）。

## 官方要求（openpi README）

## 关键代码路径（部署到 itbk 用）
- 建模型：`config = openpi.training.config.get_config("pi05_droid")` → `config.model.create(rng)` 或 `create_trained_policy(config, checkpoint_dir)`
- 推理：`policy.infer(example)`，example 由 `openpi.policies.droid_policy.make_droid_example()`
- 权重：`gs://openpi-assets/checkpoints/pi05_base`（微调用）、`pi05_droid` / `pi05_libero`（可直接推理）
- 动作维度 32（pi05 训练用 32 维，实际只用前 action_dim 个），action_horizon：droid 15 / libero 10 / base 50
